Welcome to the official static website repository for **Jayabuddha Agrotech**, a premier leader in Nepal's apiculture, organic honey production, soil testing, and agricultural consultancy services.

---

## 🌟 Key Features & Tech Stack

- **Modern Responsive Design**: Built with HTML5, CSS3, and modern Vanilla JavaScript (no heavy frameworks needed).
- **Interactive Product Catalog**: Pure Organic Honey, Natural Propolis, Fresh Royal Jelly, and Organic Bee Pollen with quick-view modal popups and direct WhatsApp ordering.
- **Hero Crossfade Background Slider**: Dynamic background photography slider with high-contrast text overlay and touch/dot navigation.
- **Background Google Form Integration**: Silent form submission directly into Google Form endpoints for instant response tracking.
- **SEO & Performance**: Optimized meta tags, OpenGraph sharing cards, vector SVG/PNG branding assets, and high Core Web Vitals performance.

## 🚀 Local Development Setup

To run the site locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/subashd44/jayabuddhaagrotech.com.np.git
   cd jayabuddhaagrotech.com.np
   ```

2. Serve locally using any static web server (e.g. `npx serve` or Python HTTP server):
   ```bash
   npx serve .
   # OR
   python3 -m http.server 8080
   ```

3. Open `http://localhost:8080` in your web browser.
